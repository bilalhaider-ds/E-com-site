8. RUNBOOKS
- RB-01 - Deploy a new application version: Push changes to main on GitHub. CodePipeline (ecom-pipeline) automatically runs Source, CodeBuild security scans, ECR push, and ECS rolling deploy. Verify http://ecom-alb-713077384.ap-south-1.elb.amazonaws.com/health returns status ok.
- RB-02 - Roll back a deployment: In ECS -> ecom-cluster -> ecom-service -> Update service, select the previous working e-com-task revision and force a new deployment, or revert the commit on GitHub main.
- RB-03 - Scale the application service: Update desired count on ecom-service in ECS (ensure enough EC2 capacity in ecom-cluster before increasing beyond 1 task on t3.micro).
- RB-04 - Troubleshoot application downtime or HTTP 503 from ALB: Check target health in bilal-blue target group, verify ECS running task count in ecom-service, inspect /ecs/e-com-task logs in CloudWatch, and test http://ecom-alb-713077384.ap-south-1.elb.amazonaws.com/health.
- RB-05 - Restore the database from a snapshot: Open RDS -> Automated backups or Snapshots -> select ecom-db backup -> Restore to new DB instance in the private DB subnet group, then update DB host in taskdef.json and redeploy.
- RB-06 - Fail over to Singapore region: Provision VPC/RDS/ECS stack in ap-southeast-1 using Terraform (ecom-terraform/), restore latest RDS snapshot copied to ap-southeast-1, push image to Singapore ECR, and switch traffic to the new ALB DNS.
- RB-07 - Handle an AWS Config or security alert: Check the resource ID and rule name in the SNS email triggered by ecom-config-noncompliant, revert the unauthorized change (for example remove port 22 from the security group), and click Re-evaluate in AWS Config until COMPLIANT.

9. KNOWN ISSUES
- CodeDeploy Blue/Green unavailable on Free Tier: CreateDeploymentGroup failed with SubscriptionRequiredException. Workaround: switched CodePipeline Deploy stage to standard ECS rolling deployment with imagedefinitions.json.
- Single-region setup and no WAF: Singapore DR, VPC peering, Multi-AZ RDS, and AWS WAF were skipped to avoid paid charges outside AWS Free Tier.
- HTTP only: No custom domain or ACM TLS certificate attached; traffic runs over HTTP on the ALB DNS.
- 1-day log retention: Log retention is set to 1 day instead of 7 days to keep CloudWatch storage within Free Tier limits.
